# Expense Tracker

Simple Python library for managing expenses.

## Features

- Add expenses
- View expenses
- Calculate total expenses

## Installation

```bash
pip install expense-tracker
```

## Example

```python
from expense_tracker import (
    add_expense,
    view_expenses,
    total_expense
)

add_expense("Food", 500, "Lunch")

view_expenses()

print(total_expense())
```
